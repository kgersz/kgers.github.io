meet octocat

Octocat is Github's adorable, unique mascot. It was designed by artist Simon Oxley of England. Oxley just so happens to be the same artist who designed Twitter's original logo. The companies both found and purchased Oxleys art from iStock.com for a surprisingly low amount of money. Although Oxley was not paid much for his logos, he still claims to find joy and pride in seeing them spread widely across the web.

intro to github

On Github you can build repositories to store and share your work, then clone these respositories from Github to your local system using command lines like mkdir and gitclone.

Github also offers pages that you can utilize to host static sites.
