What is Bootstrap?

Bootstrap is a free and open-source CSS framework directed at responsive, mobile-first front-end web development. It contains CSS and JavaScript design templates for typography, forms, buttons, navigation and other interface components. I can install Bootstrap and use Bootstrap templates. Bootstrap has definitely made it easier to stylize my webpage.
